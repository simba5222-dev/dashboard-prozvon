# Инструкции, собранные 19–20.11.2026

Здесь лежит всё, чтобы пересобрать документы с любого аккаунта: `final/` — готовые файлы (имена латиницей,
русские названия — в `README`), `sources/` — скрипты сборки и картинки, `kb/` — выгрузка базы знаний CRM (20 статей).

| Файл в `final/` | Русское название (Документы на Mac) |
|---|---|
| helpers_payments.docx | Инструкция помощникам — Разнос платежей |
| sales_manager_crm_v1_draft.docx | Инструкция менеджеру продаж — Работа в CRM (черновик) |
| sales_manager_crm_v2_kb.docx | Инструкция менеджеру продаж — Работа в CRM (версия 2 по базе знаний) |
| tkachevin_call_plan.docx | Инструкция Ткачевину — План звонков |

Сборка docx: `NODE_PATH=<папка с docx-js> node sources/crm2.js` (docx-js ставится `npm i docx`), PDF — `soffice --headless --convert-to pdf`.
Скриншоты CRM снимает `sources/crm_login.py` (вход: логин и пароль читаются из файла, который даёт владелец; в код пароли не вписывать).
Открытые вопросы владельцу по инструкции менеджера — в приложении в конце `sales_manager_crm_v2_kb.docx`.
