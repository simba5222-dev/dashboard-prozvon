Тема: POST /api/v1/diaries отвечает 500 на любое тело запроса

Здравствуйте!

Мы пользуемся вашей CRM (account-id 17) и работаем с ней через REST API
https://app.synergycrm.ru/api/v1 по ключу. Чтения и записи по заявкам,
контактам, телефонии и комментариям работают штатно.

Сейчас нам нужно ставить менеджерам задачи по заявкам автоматически —
из разбора телефонных разговоров. Создать задачу через API не получается:
POST /api/v1/diaries отвечает 500 на любое тело.

ЧТО ПРОБОВАЛИ

Заявка для примера — 733932, ответственный — пользователь 209,
тип задачи — 5305 («Теплые»).

1) Самый короткий вариант:

   POST /api/v1/diaries
   Content-Type: application/vnd.api+json

   {"data": {"type": "diaries",
             "attributes": {"name": "Проверка"}}}

   Ответ: 500
   {"errors":[{"title":"Internal Server Error","detail":"Internal Server Error",
               "code":"500","status":"500"}]}

2) То же со сроком, типом задачи, ответственным и связью с заявкой:

   {"data": {"type": "diaries",
     "attributes": {"name": "Проверка",
                    "due-date": "2026-10-01T10:00:00.000+03:00"},
     "relationships": {
       "order":       {"data": {"type": "orders",      "id": "733932"}},
       "diary-type":  {"data": {"type": "diary-types", "id": "5305"}},
       "responsible": {"data": {"type": "users",       "id": "209"}}}}}

   Ответ: тот же 500.

3) Пробовали также: привязку к контакту вместо заявки; поля
   "responsible-id", "user-id", "initiator-id" атрибутами;
   "start-time" и "end-time"; "progress"; пустые "customs".
   Во всех случаях — 500.

ПОЧЕМУ ДУМАЕМ, ЧТО ДЕЛО НЕ В НАШЕМ ЗАПРОСЕ

Проверка полей у вас работает и отвечает осмысленно. Если добавить
"status": "opened", приходит корректный 400:

   {"errors":[{"title":"Param not allowed","detail":"status is not allowed.",
               "code":"105","status":"400"}]}

То есть запрос проходит разбор и падает уже дальше, внутри обработчика.
Ключ тот же, которым мы успешно создаём заявки (POST /orders) и
комментарии (POST /comments).

ЧТО ПРОСИМ

Подскажите, пожалуйста, правильное тело запроса для создания задачи,
либо какие права нужны ключу. Если это ошибка на вашей стороне — сообщите,
когда её можно ждать исправленной.

Задачи нам нужны только по открытым заявкам, на ответственного за заявку,
типом 5305. Объём небольшой: единицы в день.
